# Arduino Web Uploader

Site simples para colar código C++ do Arduino Uno R3 e tentar enviar diretamente pela USB no Chrome ou Edge, com compilação WebAssembly no navegador.

**Estado:** protótipo. Sem teste de gravação em placa física. O Windows precisa reconhecer a porta COM e o navegador precisa permitir Web Serial.

Depois do envio do projeto, habilite **Settings → Pages → Source: GitHub Actions** para publicar.

Não exige Arduino IDE nem PlatformIO. Não altere credenciais ou drivers para contornar proteções de segurança.
